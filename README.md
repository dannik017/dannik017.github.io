# Daniel Portfolio

Personal portfolio built with React, TypeScript, and Vite. The page supports Russian, Kazakh, and English.

## Development

Requires Node.js 24+ and pnpm 12+.

```sh
pnpm install
pnpm dev
```

## Build

```sh
pnpm build
```

## Deployment

GitHub Actions builds the site and publishes it to GitHub Pages when changes are pushed to `main`. The repository must be named `dannik017.github.io` for the site to use the root address [https://dannik017.github.io](https://dannik017.github.io). In the repository settings, set **Pages → Build and deployment → Source** to **GitHub Actions**.
